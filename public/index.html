03

特性

SIX SURFACES · ONE PANEL

变量面板

读接口永远返回明文真值，每个变量可单独锁定；整表读取比逐条快约 4 倍。

云数据双库直改

project / user 双作用域直接读写，保存走双通道，失败必回滚镜像并明确报错。

还原点

变量、列表、云数据打包成命名快照，应用失败自动回滚，绝不留半应用状态。

插件体系

一个 .js 就是一个插件：bodySig 指纹校验、HTML 消毒、toString 白名单全套环境红利。

配置包

重命名规则、锁定表、还原点、插件清单走一份 JSON 主配置，条目级合并不清空用户数据。

多面板

工具页 SB3 工具箱、飞书页直连文档图床、系统页还原点与诊断；rAF 合帧拖拽零布局抖动。
