安装 VaIMod

ccw.site 的隐形变量手术台：明文读写每一个变量、直改云数据、一键回滚任意时刻。装好后打开任意作品页，面板自己出现。

自动更新 document-start 注入 closed Shadow DOM 仅 ccw.site 生效
点击安装脚本 → Releases ↗
https://vaimod.github.io/VaIMod/VaIMod.user.js
01

安装 Tampermonkey

需要一款用户脚本管理器，推荐 Tampermonkey（Chrome / Edge / Firefox 均可，Violentmonkey 同样支持）。

02

点击上方「安装脚本」

Tampermonkey 弹出安装确认，源码可先审计再装。之后每次发布新版本自动更新，无需手动重装。

03

打开 ccw.site 任意作品

面板自动挂载（closed Shadow DOM，页面脚本探测不到）。右上角齿轮进设置；防火墙等能力在插件页按需导入。
