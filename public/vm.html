VM 钩子体系

八路获取通道 + 评分制自动选优 + 3 秒看门狗自愈 + 反检测七组钩子。 VM 根据当前环境自动选择最优方案——不靠写死优先级，靠实时战果。

01

八路获取通道

6 POLLED + 2 EVENT-DRIVEN
#通道类型原理
1redux store轮询三路子扫描：window 五键名 / fiber Provider props.store / DevTools 根，从 state.scratchGui.vm 取引用
2react fiber轮询五策略遍历 + DevTools 子路；多 fiber key 全部收集逐个尝试，防站点重建残留 key 遮蔽
3三全局键轮询window.vm / _vm / Scratch.vm 直查
4Eureka轮询站点专属挂载点探测
5iframe轮询同源子框架内扫描
6全局扫描轮询枚举 window 可枚举键，isVMLike 判定（空值 / 异常安全化，半残假 vm 不炸桥）
7bind 劫持事件驱动Hook Function.prototype.bind，vm 方法被 bind 时顺藤摸瓜；命中即还原，零残留
8setter 赋值陷阱事件驱动在 window.vm / _vm 上布访问器，赋值一发生立即捕获——比任何轮询早一个节拍
02

评分制自动选优

SCORE-AUTO-SELECT

不是「上次谁成功下次就谁先」——是每轮发现前实时重算排名。三个因子相乘，谁的综合分高谁先上：

// scoreOf(channel) score = (wins + 1) / (tries + 2) // Laplace 平滑成功率：没打过的通道也有出场机会 × 1 / (1 + avgLatency / 50ms) // 速度因子：越快越高 × 1 / (1 + age / 10min) // 新鲜度因子：战果放久会过期 // rankChannels 每轮重算： 有战果通道 → 按分数降序 未尝试通道 → 按基线顺序 试过没命中 → 垫底

实测收敛：fiber 主导环境里 fiber 得分 0.742 严格压过 redux 0.483——环境变了，排名跟着变，无需人工干预。

03

VM 劫持加固

vm-hardening · SELF-HEAL
W

引用看门狗3s

HEALTH CHECK · REBUILD
每 3 秒验证 vm 引用健康；站点重建 vm 自动重连且锁定跨重建存活。失效即走评分制重建通道。
S

巡检登记表Symbol

NON-ENUMERABLE · RANDOM KEY
登记表寄存在 globalThis 的不可枚举随机 Symbol 上——页面枚举不出来、拿不到、更删不掉。
L

访问器锁≤100ms

DESCRIPTOR CHECK PER TICK
锁留存自家 setter 引用，每拍校验 descriptor；锁被绕掉 100ms 内重新钉死。
P

原型逃逸封死__proto__

SANDBOX HARDENING
沙盒封死 __proto__ 原型逃逸路径；三项幂等巡检（vm-ref / vm-locks / lp-tap）静默自愈。
04

反检测七组钩子

vm-antidetect · CONDITIONAL SPOOF

核心原则：条件式伪装——正常环境零改动，一个字节都不碰；只在指纹被读取时给出确定性一致的答案。

GPU · per-context 确定性

同一 WebGL context 两次查询返回同一渲染器——随机化反而露馅，确定性才是伪装。

Canvas · 零残留

导出后还原原像素，读回来的画布与写入的完全一致，不留噪声痕迹。

音频 · 指纹扰动

AudioContext 指纹输出确定性微扰，跨会话稳定。

navigator / screen

硬件并发、内存、分辨率等高危指纹项条件式覆写。

时区 · 双口径一致

Intl 与 Date 两套时区口径严格对齐，交叉比对不出破绽。

行为 · 可见性真值口

伪装 visible 的同时，自家巡逻读 trueHidden() 原生真值——伪装绝不门控自己的防线。

  • 取证自检——forensicSelfTest 复刻检测器 v3.3.4 的取证面：toString 无 \ 与 call、arity=3、name 非空、无 prototype、globalThis.toString 无 ?、querySelector 无 select，5s 缓存全只读
  • toString 白名单——包装过的原生方法登记进 Function.prototype.toString 白名单并同步 name，查出来永远"是原生的"
  • 零残留——伪装动作不留下可回溯的痕迹（像素还原、bind 捕获即还原、markNative 赋 undefined 非 delete）
  • 条件式——环境正常时不装、不包、不改，检测面本身就最小化
