## 2 · 相对原版**新增**的能力

### 2.1 面板骨架（原版只有一个表单）

| 能力 | 说明 |
| --- | --- |
| 悬浮球 + 可拖拽/可拉伸面板 | 位移走 transform 合成层 + rAF 合帧；宽高自适应解耦（宽度只由 Tab 集合驱动） |
| 多标签页 + 拖拽排序 | 侧边栏式 Tab，长按拖拽排序带磁吸动画，逐页显隐 |
| 设置覆盖层 | 主题色（六色预设）、异步加载、快照补齐、标签页排序、插件管理、本地重命名、清空本地记忆、恢复默认 |
| 配置备份与迁移 | 一键导出/导入完整配置包（变量、别名、云数据、机器人、快照、回收站、设置、插件源码） |
| 窄屏自适应 | 贴底全宽，分段控件自动折行 |

### 2.2 变量页（原版能力的超集）

保留原版的「查看 / 修改 / 锁定 / 导入导出配置模板」，新增：
新建变量、删除进回收站、本地显示别名、分组折叠（跨会话记忆）、加入监视器、跨目标同名变量识别。
**`getVariables()` 一律返回明文**（编码只发生在单次出网封包处），UI 有 4 条独立读路径互不干扰。

### 2.3 云数据页（原版完全没有）

作品云数据 / 用户云数据查看与编辑；**锁定**——设定值与间隔后周期自动写回，防作品逻辑覆盖；删除进回收站。

### 2.4 工具页

同变量跨目标批量「设为值 / 新建缺失 / 批量删除」；带前缀变量的 JSON 序列化 ⇄ 恢复；列表快捷增删改。

### 2.5 飞书页

从变量内容（含云变量）自动捕获 webhook 登记机器人；文本 / @全员 / @成员 / 图片 / 卡片 / 文件消息；
上传改走 ccw OSS；支持拦截页面自身的消息请求（内嵌 UI）。

### 2.6 系统页

快照备份与一键还原（首次进入自动生成初始快照；还原时缺失变量可选自动补齐）；
**三个回收站**（变量 / 作品云 / 用户云），支持单项还原、全部还原、彻底删除。

### 2.7 插件系统（原版没有）

- 插件 = 一个 `.js` 文件，调 `VaIMod.plugin({…})` 声明；装好后成为面板里的独立标签页
- 两种类型：`ext`（带界面扩展）/ `patch`（无界面安全补丁，参与内部管道）
- 四段内容独立编译：`html`（声明式、注入前净化）/ `css`（自动作用域限定）/ `code` / `refresh`
- 异步加载定义 `async`：`waitVm` / `load` / `timeout` / `lazy` / `code`
- `def.settings` 四种设置项；`def.market` 市场元信息；`@标签式清单`（注释里写清单）
- 上传去重（源码指纹）、同 id 覆盖升级（保留启用态）、完整性指纹 `bodySig`（落盘条目被改写 → 拒载并告警，**条目保留在盘上可修复**）
- 受控能力面 `ctx`：`store` / `settings` / `onSettings` / `variables` / `onVariables` / `write` /
  `ui`（17 个组件工厂）/ `toast` / `project` / `alias` / `net` / `patch.hooks`
- 管道钩子 `variable:write`：每补丁每管道一个钩子、全局上限 32、连续 3 错自动熔断、随生命周期注销

### 2.8 本地重命名配置系统（原版没有）

把作品里的**真实变量名**映射成面板显示名。**语义红线：只改显示**——不新建变量、不改作品里的变量名、
不写任何值、对项目与云端零影响（探针断言：导入后整份 vm 快照逐字节一致）。
兼容 4 种输入格式：`rules` / `variables`（`cave-vars.json` 可直接导入）/ `displayNames` / 扁平表。
显示优先级：变量页手动重命名（按 id）> 规则表（按名，支持 `*` 通配）> 原名。

### 2.9 网络防火墙（原版没有）—— **可分发的独立插件**

出网审计：钩住 fetch / XHR / beacon / WebSocket 四个通道，按载荷体积与字段特征判定
`third`（普通第三方）/ `block`（命中黑名单）/ `exfil`（疑似外发变量或存档）/ `allow`（白名单）。

**形态是可导入的独立插件 `docs/plugin-net-firewall.js`（`id: net-firewall`）**：
- **不导入就完全没有这个功能** —— 没有标签页、没有设置项、没有任何网络钩子；（用户明确要求）
- 导入后自带一个标签页，`async.lazy: false` 常驻（不打开标签页也在审计）；
- 模式（关闭 / 监视 / 拦截）与域名规则存在**插件自己的私有存储**里，**不进本体设置、不进配置包导出**；
- 引擎用 `window[Symbol.for('vaimod.net-firewall')]` 单例 + 引用计数：常驻实例与标签页实例
  切页时一卸一装，靠引用计数保证钩子不闪断、**日志不被重建清空**。

本体侧只留 `src/core/net-internal.ts`（两个纯函数：`markInternalXhr` / `isInternalXhr`）
与 `ctx.net` 两项能力（`isInternalXhr` / `markNative`）—— 本体**不内置任何网络钩子**，
也**不认识「防火墙规则」这类业务概念**。

## 5 · 性能

| 项 | 处理 |
| --- | --- |
| 变量列表 | 引用复用（下沉到桥接层）+ 长列表跳过视口外绘制 |

## CSense 拦截器反制（v0.1.33 起）

针对 ccw 社区扩展「CSense 拦截器」v0.1.5a3（Chen-Jin @ CCW）新增 `src/core/csense-guard.ts`，
在启动链 ②′ 位（XSS 守卫之后、官方云钩子之前）document-start 即生效：

- **它的检测面**：DOM 扫描（`html>div[style*="rgb"] *` / `body>div:empty[style*="inset"]` /
  shadow-root 探测 / iframe contentWindow）、`vm.loadProject` 原生性、`ccwAPI.Extension`、
  localStorage `__csense-plugins` / `ext_csb3.2*`、cookie、navigator.userAgent。
- **它的上报通道**：fetch(keepalive) POST → `supabase.co/rest/v1/csense_detections`（带 publishable
  apikey）；外泄信标 → `d.chen-jin.dpdns.org/csdetected?`。userscript 用户极易被通用启发式误伤。
- **反制**（被动、窄口径、零站点影响）：
  1. fetch / XHR / sendBeacon 命中上述两个 CSense 专属端点 → 本地合成假 200（不出网）。
     CSense 拿到成功响应不会重试风暴；XHR 假完成走 dispatchEvent 全量派发
     （readystatechange+load+loadend，防 addEventListener 型调用方悬挂）。
  2. 只读特征扫描（`__csense-plugins` / `ext_csb*` / `.csense-window` / cookie），诊断入口
     `__vaimod_debug.csense()`（需 vaimod_debug=1）。
  3. 检测面对策汇总（均为既有能力）：closed shadow DOM、lp-guard 旁路 + toString 白名单、
     stealth 遍历过滤、品牌键与 csb* 无交集、不注册任何 extension。
- **边界**：Location.assign/replace/href 为 [Unforgeable] 不可包装（CSense 主通道是 fetch，
  导航式上报未在载荷中出现）；其 m.ccw.site 热更新 JS 一律透传（属扩展自身资源，不主动破坏）。

### CSense 反制 v2（同日补强：三板斧全覆盖）

用户实测反馈「拦截无效」——v1 只掐了网络上报，未覆盖其跳转与遮罩。载荷字符串表
证实其完整链路后，csense-guard 补齐三道拦截：

1. **拦截检测**：网络咽喉不变（fetch/XHR/sendBeacon 命中 csense_detections →
   假 200 不出网）；检测面本身由既有能力压成全负（closed shadow、toString
   白名单、品牌键无交集、不注册 extension）。
2. **拦截跳转**（新增，三层咽喉）：
   - Navigation API `navigate` 事件 preventDefault —— 唯一能拦
     `location.href = url` 直赋值的钩点（Chrome 102+），覆盖 assign/replace/
     window.open 同页/链接/表单；
   - `Location.prototype.assign/replace` 包装（location 属性本身 [Unforgeable]
     不可定义，但方法在原型上可安全包装，markNative 进 toString 白名单）；
   - `window.open` 包装，命中返回假 window 桩（避免其按「弹窗被拦」重试）。
3. **允许作品继续运行**（新增）：MutationObserver 即时纠正（childList 挂
   documentElement + body，铁律：即时纠正不能靠巡检）——div.csense-window
   遮罩一插入 DOM 立即移除；跳转被拦 + 遮罩被清 + 上报不出网 → 作品正常可玩。

`__vaimod_debug.csense()` 计数扩为 fetch/xhr/beacon/nav/overlay 五路。
黑名单仍窄口径：仅 csdetected 域与 supabase csense_detections 端点，
其余导航/请求（含 m.ccw.site 热更新）零接触。
