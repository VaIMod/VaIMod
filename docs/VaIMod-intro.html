变量面板。所见即明文

VARS · READ / WRITE / LOCK

读接口永远返回明文真值——不编码、不混淆，改了什么就是什么。 每个变量可以单独锁定：锁住的值对游戏逻辑只读，防手滑也防覆盖。 系统临时槽位会被自动识别并标锁，避免误改跨过程暂存。

明文快照 · 整表读取比逐条快 ~4x 本地重命名 · 强制开启 value:"*" 自带检测 监视器开关

云数据。双库直改

CLOUD · PROJECT / USER

作品库与用户库两个作用域直接读写，本地镜像实时同步。 保存走双通道，任何一路失败都会回滚镜像并明确报错—— 绝不出现「提示已保存，实际云端没写进去」的静默分叉。

project / user 双作用域 失败必回滚镜像 支持整键增删

还原点。任意时刻可回退

RESTORE POINTS · SNAPSHOT / APPLY

变量、列表、云数据打包成命名快照。应用时逐项写回， 云数据写入失败自动回滚本地镜像，不会留下半应用状态。 快照可以导出成 JSON 分享，导入时结构校验，坏数据直接拒绝。

导入前结构校验 应用失败回滚 JSON 导入 / 导出

插件体系。能力无上限

PLUGINS · IMPORT / SANDBOX EDGE / INTEGRITY

一个 .js 文件就是一个插件。导入后自动获得全套环境红利： UI 住进 closed shadow、源码落盘即指纹校验（bodySig）、 HTML 部分强制消毒、包装原生方法有 toString 白名单接口。 异步装载支持 waitVm → load → code 三段式，防火墙等网络能力全部以插件形式分发。

bodySig 启动校验 · 改写即隔离 sanitizePluginHtml ctx.net / ctx.vm / ctx.ui 防火墙 = 独立插件

配置包。一次携带全部

BUNDLE · ONE FILE, EVERYTHING

变量重命名规则、锁定表、还原点、插件清单全部走一份 JSON 主配置。 导入按条目合并而非粗暴覆盖，插件包可声明 pluginsOnly 只装插件不动本地数据。

rename / lock / markers / plugins 条目级合并 · 不清空用户数据 pluginsOnly 导入

更多面板。按需生长

TOOLS · FEISHU · SYSTEM · FIREWALL

工具页内置 SB3 工具箱；飞书页直连文档与图床；系统页集中 还原点、回收站与运行诊断。所有页面共用同一套拖拽、 自适应与动画引擎——合成层位移、零布局抖动。

安全系统如何运作

BOOT CHAIN · DEPTH BY LAYER

防御不是事后补丁，而是一条在页面第一行代码之前就排好队的纵深链。 每层只做一件事，上层失效下层兜底：

⓪

SecureGuard 前哨secure-guardFront

DOCUMENT-START · 第一优先级
抢先净化易被利用的全局实例，变量名保护同步上膛——在游戏代码有机会动手之前。
⓪′

SigGuard 双注册咽喉sig-guardFront

EXTENSIONS.REGISTER + EXTENSIONMANAGER
官方扩展注册与项目扩展管理器双路设卡，新注册的类原型逐个过检；作品加载完成的 burst 信号触发全量重扫，2 秒 tick 兜底漏网。
①

Stealth 隐身宿主stealth.ts

CLOSED SHADOW DOM
面板的全部 UI 住进 closed 模式 Shadow DOM：页面脚本 querySelectorAll 永远查不进去，创建时登记的宿主清单是唯一入口。
②

XSS 防线xssGuard

SANITIZE AT BOUNDARY
一切进入 UI 的动态内容在边界消毒：脚本、iframe、内联事件、伪协议一律剥除。
③

云 API 旁路hookOfficialCloudApi

PASSTHROUGH TAP · NO IMPOSTOR
对官方云接口挂纯旁路透传的捕获钩子——绝不伪装 vm 实例、不改写访问器，游戏加载照常、数据照常，我们只是看着。
④

蜜罐哨兵honeypotGuard

DECOY · 8S PATROL
布下探测者才看得见的诱饵面：谁伸手碰诱饵，等于自报家门。8 秒一轮的巡逻持续确认诱饵完好。
④+

飞书 & UI 卫兵feishuGuard · uiGuard

ATTRIBUTE OBSERVER · 1S PATROL
uiGuard 给宿主挂属性观察器：敌扩展写入的隐藏样式被即时回滚，不等巡检；zIndex 与挂载点被挪动也会自动归位。
⑤

Veil 动态面纱veilGuard

DYNAMIC VEIL CHAIN · ONIDLE
boot 完成后叠加动态面纱链：对外呈现的接口面随时间变化，探测者拿到的是永远对不上号的快照。
VM

ScratchVM 桥接 + 早期捕获capture-early

25MS POLL · LOADPROJECT TAP
document-start 起 25ms 轮询盯住 window.vm；loadProject 挂幂等旁路 tap，VM 加载多快都逃不过捕获，绝不双重包装。

Integrity · 完整性

插件源码落盘即算 bodySig 指纹，每次启动复验；localStorage 条目被外部改写 → 隔离扣留并亮出告警，宁可不加载，不带毒启动。

Anti-Fingerprint · 反指纹

包装过的原生方法登记进 Function.prototype.toString 白名单并同步 name——反作弊最常查的一处，查出来永远"是原生的"。

Net Marking · 网络标记

本体请求用 WeakSet 打标：页面探测不到也伪造不了。网络类插件据此放行内部流量，用户拉黑域名不会误伤云数据。

Self-Patrol · 自巡逻

全部常驻轮询可见性门控：页面隐藏即休眠，回前台立刻补跑。守护自己，不浪费你的电池。

  • 只旁路，不伪装——捕获永远透传，绝不冒充 vm 实例
  • 读接口必明文——不做非幂等编码，UI 四条读路径全部一致
  • 失败必回滚——双通道任一失败，镜像与云端绝不分叉
  • 锁值不进面板——锁定元数据与业务数据物理隔离
  • 动静分层——位移走合成层，绝不让动画逼出整页布局
  • 插件同级信任——插件代码是页面级脚本，享受保护而非沙箱隔离
