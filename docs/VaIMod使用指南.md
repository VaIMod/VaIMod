# VaIMod 使用指南

VaIMod 是一个浏览器用户脚本（userscript），为 ccw.site 等类 Scratch 平台提供变量增强、云数据管理、快照备份、飞书通知和插件扩展能力。全部功能通过一个悬浮面板完成，注入采用 Shadow DOM 隐身方式，不影响作品本体运行。

## 一、安装

1. 浏览器先装用户脚本管理器（Tampermonkey / Violentmonkey 等）。
2. 安装 VaIMod：开发模式访问 `http://127.0.0.1:8899/VaIMod.user.js` 按提示安装（本地服务实时同步最新构建）；或直接导入 `dist/VaIMod.user.js`。
3. 打开任意作品页，右下角出现 VaIMod 悬浮球（FAB），点击展开面板。

面板未获取到 VM 时正文只显示「等待获取vm」；进入作品后自动连接。右上角齿轮为**常驻**设置入口（任何标签页、任何状态下都可见）。

## 二、界面总览

- **悬浮球（FAB）**：展开/收起面板。
- **面板头部**：收起按钮、设置齿轮（常驻，任何时候都能进设置）。
- **标签栏**：内置五个标签页——变量 / 云数据 / 工具 / 飞书 / 系统；**默认面板只有「变量 + 云数据」**，工具 / 飞书 / 系统默认关闭，在设置的「标签页」里打开即可（新版本新增的内置标签页也一律默认关闭，不会悄悄改变你的默认面板）。安装插件后会追加插件页。长按拖拽可排序，每页可在设置里开关显隐。
  网络防火墙**不是内置功能**：它是一份可分发的独立插件（`docs/plugin-net-firewall.js`）。
  **不导入就没有这个功能**——没有标签页、没有设置项、没有任何网络钩子。
  要用的地方：设置 →「插件」→ 上传该 `.js` 文件 → 标签栏出现「网络防火墙」页（默认「关闭」模式）。

## 三、变量页

- 实时查看并**编辑**当前作品全部变量（含云变量），改动立即写回作品。
- 新建变量、删除变量（删除先进**回收站**，可还原）。
- **显示别名**：只改本地显示名，不动物理真实名；支持一键恢复全部原始名。
- 变量分组可折叠，展开/折叠状态跨会话记忆。
- 可把变量加入监视器单独盯值。

## 四、云数据页

- 查看并编辑作品云数据 / 用户云数据。
- 支持**锁定**：设定值与间隔后，VaIMod 按周期自动写回，防止被作品逻辑改掉。
- 删除的云数据同样先进回收站。

## 五、工具页

- **同变量批量**：输入变量名，可跨目标批量「设为值」「新建缺失」（某目标没有该变量时补建）、「批量删除」（进回收站）。
- **前缀 JSON 序列化 ↔ 恢复**：把带前缀的一组变量打包成一个 JSON 对象导出/恢复，适合结构化存档。
- **列表快捷操作**：对指定列表做快捷增删改。

## 六、飞书页

- **机器人管理**：「扫描变量/列表」自动从变量内容（含云变量）里捕获 webhook 一键登记，也可手动添加；机器人可自定义名称。
- **消息发送**：内容类型支持 文本 / @全员 / @成员 / 图片key / 卡片JSON / 捷径JSON / 文件/图片。

## 七、系统页

- **快照**：首次进入自动生成「初始快照」；也可手动创建多个快照，随时一键还原（还原时缺失的变量/目标可选自动补齐，见设置）。
- **回收站**：变量 / 作品云 / 用户云三个桶；支持单项还原、一键全部还原、彻底删除或清空。

## 八、插件

- **安装**：设置页插件管理 →「上传插件 JS」，支持一次多选；重复代码自动跳过，新版本自动升级。
- **启停**：每张插件卡有开关，停用后其标签页随之隐藏。
- **设置项**：插件可声明自己的设置（开关/文本/数字/下拉），在卡片内直接改。
- **导出**：
  - 单个：卡片上的「导出」→ 下载 `.plugin.js` 源文件；
  - 批量：顶部「导出全部」→ 下载 `VaIMod-plugins-*.json` 配置包，用面板「导入配置」即可整包装回（只装插件，不动其它数据）。
- 开发自己的插件见《插件开发文档.md》（附模板 `plugin-template.example.js`）。

## 九、设置页

面板头部齿轮打开，包含：

| 设置 | 说明 |
|---|---|
| 异步加载 | 切页先给反馈再挂载内容，更跟手（默认开） |
| 快照还原补齐 | 还原快照时缺失的变量自动重新创建 |
| 主色调 | 六色预设，驱动面板主题色 |
| 标签页 | 拖拽排序（带磁吸动画）+ 开关控制显隐 |
| 本地重命名 | **强制开启、无开关、设置页无栏目**（2026-09-25 起）。按「真实变量名 → 显示名」改面板显示，数据由**主配置携带**（`aliasConfig` 规则表 + 变量条目 `rename` 字段，见《配置文件说明》第八节）。**只改显示**：不新建变量、不改作品里的变量名，对项目与云端零影响 |
| 插件 | 插件管理（上传/启停/导出/卸载）。**网络防火墙就是通过这里导入的独立插件**（见第九节） |
| 清空本地记忆 | 删除机器人记录、快照、回收站、别名、分组记忆（不影响作品本体） |
| 恢复默认设置 | 图标按钮，一键复位全部设置与标签页顺序 |

## 十、配置备份与迁移

- 面板头部「导出配置」：一键打包变量、别名、云数据、机器人、快照、回收站、设置、插件源码。
- 「导入配置」：选择 JSON 一键还原；旧版纯变量 JSON 也兼容。
- 变量部分支持 `"*"` **自动检测通配模式**——不写死变量名，导入时按当前项目动态套用默认值/锁定策略，新增变量自动纳入。写法与规则详见《配置文件说明.md》。

## 十一、安全与反制

VaIMod 内置防检测与反制模块（针对恶意/作弊检测类扩展的数字签名刺探、变量名清空攻击、隐藏样式注入等），随脚本自动运行，无需任何配置。为避免互相干扰，不建议与其它同类修改型扩展同时启用。

## 十二、常见问题

- **面板不出现**：确认脚本管理器已启用且匹配当前站点；刷新页面；VM 未就绪时面板会显示等待状态而非消失。
- **变量值显示异常**：先点面板刷新按钮重读；若曾手动改过导出 JSON 的结构导致双重编码，删掉该条重新配置即可。
- **游戏类作品（如 Cave）运行异常**：请确认使用最新版 VaIMod——旧版对加载器的伪装已移除，新版不会干扰作品自身的关卡/项目加载。
- **手机/窄屏**：面板自适应贴底全宽，分段控件自动折行。
